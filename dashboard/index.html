System Architecture & Dataflow

ForensiTap-ESP32 executes a multi-tiered forensic telemetry pipeline spanning raw hardware RF ingress, FreeRTOS queueing, online statistical feature extraction, heuristic anomaly detection, and tamper-evident cryptographic logging.

📊 Multi-Tiered Architecture Pipeline
Tier 1: Physical Radio Ingress & Promiscuous Sniffer (Core 0)

Hardware 2.4 GHz 802.11 PHY operating in promiscuous monitor mode. The Promiscuous RX callback runs directly within high-priority ISR context. It performs zero memory copies and zero heap allocations, extracting pure metadata (RSSI, frame length, frame type/subtype, channel, sequence control) into a lightweight 32-byte wifi_frame_meta_t struct.

Tier 2: FreeRTOS Ring Queue & Decoupling Buffer

A thread-safe 64-element FreeRTOS queue safely absorbs packet rate bursts up to 300+ frames per second without dropping frames or triggering watchdog timeouts. The queue decouples the high-speed RX ISR from downstream statistical math.

Tier 3: Metadata Processing & LRU Device Tracking Table

De-duplicates and indexes observed transmitters using a 32-slot Least Recently Used (LRU) hash table. Tracks MAC addresses, transmitter roles (AP vs Station), packet frequencies, and smoothed RSSI values without storing raw payloads—ensuring complete user privacy and zero GDPR/wiretap compliance exposure.

Tier 4: Statistical Feature Engine (Welford's Algorithm)

Calculates dynamic running metrics across sliding 10-second aggregation windows: Window FPS, Byte Rate (KB/s), Average Frame Size, Management Frame Ratio, and Traffic Burstiness Score. Computes running mean and variance in a single pass with numerical stability using Welford's algorithm to generate real-time Z-scores.

Tier 5: Edge Heuristic Anomaly Detector

Runs 5 deterministic detection rules on each feature window: TrafficSpikeRule (Z-Score > +3.0σ), MgmtAnomalyRule (Management frame ratio > 60%), NewDeviceRule (Unrecognized MAC or rogue AP), BurstAnomalyRule (Burstiness score > 4.0), and SystemHealthRule (Low heap / buffer drops).

Tier 6: Cryptographic Forensic Logger (SHA-256 Blockchain)

Every alert and significant state change is minted into a tamper-evident evidence block: Block_Hash = SHA-256(Index || Timestamp || Event_Type || Description || Prev_Hash). An in-memory 32-block ring window provides continuous mathematical integrity checks via one-click auditing.

Tier 7: Coexistence & Embedded REST API (Core 1)

The ESP32 maintains Wi-Fi Station connection while concurrently operating in promiscuous mode on Channel 11. An embedded HTTP micro-server serves JSON telemetry endpoints (/api/health, /api/stats, /api/features, /api/devices, /api/alerts, /api/logs, /api/logs/verify, /api/export).
