Dual-Core FreeRTOS Pipeline & Software Engine

ForensiTap-ESP32 achieves zero packet loss during attack storms by decoupling high-priority physical radio ingestion (Core 0 ISR) from analytical computation and cryptographic hashing (Core 1).

📊 7-Tier ForensiTap Architecture Pipeline
Tier 1: Physical Radio Promiscuous RX Sniffer (Core 0)

Hardware 802.11 PHY in promiscuous mode on Channel 11. Callback executes directly within high-priority ISR context. Zero heap allocations; extracts pure metadata (RSSI, frame length, frame type, subtype, channel, sequence control) into a lightweight 32-byte FrameObservation struct.

Tier 2: FreeRTOS Ring Queue Buffer

A thread-safe 64-element FreeRTOS queue safely absorbs packet rate bursts up to 350+ frames per second without dropping frames or triggering watchdog timeouts.

Tier 3: Metadata Processing & LRU Device Tracker

Indexes observed transmitters in a 32-slot Least Recently Used (LRU) hash table. Tracks MAC addresses, transmitter roles (AP vs STA), packet frequencies, and smoothed RSSI values without storing raw payloads—ensuring complete user privacy and zero wiretap compliance exposure.

Tier 4: Statistical Feature Engine & Adaptive EWMA

Calculates dynamic rolling metrics across 10-second sliding windows: Window FPS, Byte Rate, Management Ratio, Deauth Rate, and Traffic Burstiness. Computes running mean and variance in a single pass using Welford's algorithm coupled with an Exponentially Weighted Moving Average (EWMA) baseline.

Tier 5: Deterministic Anomaly Detector & Edge ML

Runs 7 deterministic detection rules: DeauthFloodRule (direct subtype 0x0C tracking), TrafficSpikeRule (Z-Score > +3.0σ), MgmtAnomalyRule, EvilTwinRule (instantaneous RSSI spoofing shift ≥ 28 dBm), BurstAnomalyRule, SystemHealthRule, and an embedded Edge Decision Tree Classifier.

Tier 6: Cryptographic Forensic Logger (SHA-256 Hash Chain)

Every alert and state change is minted into a tamper-evident evidence block: Block_Hash = SHA-256(Index || Timestamp || Event_Type || Severity || Description || Prev_Hash). An in-memory 32-block ring window provides continuous mathematical integrity checks via one-click auditing.

Tier 7: Embedded REST & WebSerial API (Core 1)

Maintains Wi-Fi Station connection while concurrently operating in promiscuous mode on Channel 11. Serves JSON telemetry endpoints (/api/health, /api/stats, /api/features, /api/devices, /api/alerts, /api/logs) with sub-15ms response latency.
